Rows of 32 pixels: the source ramp is i = 0..31 (5 bits) in the channel of the first letter (P = red ramp with bit 15 set, S = red ramp, 1S = source).

Rules read from these pages (16-bit pixel = P RRRRR GGGGG BBBBB):
- MS = PIN: multiplier R = bits 13..11 + 1, G = bits 10..8 + 1, B = bits 7..5 + 1 (one 9-bit field, three by three). The P bit has no effect.
- MS = PDC: per channel, multiplier = c[4:2] + 1, divider from c[1:0]: 0 = /16, 1 = /2, 2 = /4, 3 = /8; results are floored and clamped at 31.
- AV (USEAV): bit 0 = subtract the second source, bit 1 = second source signed on 5 bits, bit 2 = no clamp (wraps modulo 32), bits 4:3 = 0 /1, 1 /2, 2 /4.
- AV bits 4:3 = 3 (E3, one point only): v = i * f + 4 with f = 1/2, 4, 2, 1 for i[1:0] = 0, 1, 2, 3: the divider of the first source then comes from the pixel; the second source (24) gives 4, not understood.
- 8-bit uncoded: R = rrr << 2, G = ggg << 2, B = bb << 3, no bit copied in the low bits. TLLSB 2: blue bit 0 = blue bit 4; TLLSB 0, 1, 3 give 0 here.
- 1-bit and 2-bit coded pixels take the PLUT entries directly.
