# Interpretation
# - On the console, bit 15 of MCTL never falls back in this window (N = 0), as in REG TEMPS (register times).
#   In Opera and in the core, it falls back every time (N = 16).
# - 570 is 204 bytes after 578 on the console, 208 in Opera. With 574 = 0 (Opera: FFFFFFFC, transfer finished),
#   the console would be one word from the end of a 52-word buffer. Hypothesis.
# - The controller data are not where Opera puts them: the 28 words before 570 are zero on the console.
#   15 words of the buffer (between views A and B) were not displayed.
# - PISTOLET CIBLES (gun targets) looks for the gun identifier in this same area: on the console, this test probably cannot find it.
# - INT: bits 3 and 7 on the console (88), bits 0, 3 and 7 in Opera (89), bits 0 and 7 in the core (81).
