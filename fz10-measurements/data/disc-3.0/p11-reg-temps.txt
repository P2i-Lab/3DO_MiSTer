# Interpretation
# - M008 (MCTL): on the console bit 15 is 1 in the 128 reads; in the core it changes 8 times (cleared by PLAYER_INT, MADAM.sv:242).
#   On the console, if it falls back, it is for less than about 3 % of the time (0 reads out of 128).
# - M040: counter of at least 11 bits on the console, changes on every read; the core always returns 0.
# - M00C, C024, C084, C088, C060: constant on the console, 0 in the core (differences already seen with disc 2.3, these are not read flukes).
# - M010: E2800001 constant, consistent with the value left on the bus (see disc 2.3).
# - C040: 88 on the console (bits 7 and 3), 81 in the core (bits 7 and 0), constant over the 128 reads.
# - C030, C034, C03C, C118, C130: same bits changing on the console and in the core.
# - C100 / C108: system time timers; the values depend on the time elapsed since boot.
